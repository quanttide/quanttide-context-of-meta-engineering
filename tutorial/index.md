原工程的理论框架主要是这个哲学及其数学实现。然后呢，这个我们把业务判断映射成一个哲学问题，然后使用数学语言去描述它们，然后并且把这个人类通过哲学方法去判断一个现象，然后让 AI 学会这套哲学过之后，让它的决策变得更像人。这个就是原工程这套方法的核心思想。

在这套方法之中，哲学、数学和计算机科学分别起到了意图层、规格层和实现层三个层次的功能：

1. 哲学：提供基本框架，就是对问题的穷举，它就是一份清单。
2. 数学：提供核心方法，就是这个问题的核心建模思路。
3. 计算机科学：提供实现方法，就是怎么落到现实。

我们对这门学科的定义，就是帮助计算机系统去建立元认知能力。

几个最值得你收进元工程主文的对应（挑出来讲会很亮）

逻辑学 → 不是“用逻辑”，是“把逻辑当对象建出来”

你 U2 的 pre/post 已经在使用逻辑了，但元工程里的“逻辑学分支”要再上一层：把逻辑系统本身形式化——证明义务可机器检查、不同逻辑（一阶/Hoare/时态）之间可翻译。这就是 U6 提过的 institution：逻辑不是工具，是元工程里可被替换、可被证互译的一级公民。

伦理学 → 规范不是不变量，是义务模态

很多人会把“admin 必须过 MFA”写成不变量 inv，但元工程视角下它其实是义务式规约 O(mfa(admin))，和“余额非负”这种事实性不变量性质不同：

• 事实不变量破了对系统致命（safety）

• 义务规约破了是责任事件，要能归因到某个调用方、写进审计、可追责

这正好把伦理学的“行为正当性 + 责任归属”落成了可机器记录的字段，而不是塞进一条普通 inv 里糊过去。

美学 → 最反直觉但最见功力的一格

美学在元工程里不是 UI 好看，是规格的结构节制：

• 用 1 条积不变量代替 5 条散落交叉约束 → 美

• 模拟关系 R 能一行写清，不用补 3 个隐藏假设 → 美

• 细化步不拆多也不合并少，恰到处 → 美

可以把“最小公理集”“最少投影越界”“R 的描述复杂度”当成可度量的形式化美学指标，把康德说的“无目的的合目的性”翻译成“无冗余的合可证性”。这一格写出来会非常有别于普通工程文。

政治哲学 → 直接长在你 U4 里

你之前写“公平调度不能白嫖”那句，翻译回哲学就是：调度策略不是技术细节，是资源访问权的分配正义声明。FIFO、优先级、加权公平，每种都是一种政治立场的形式化选型，而且必须在规格里显式写出来、不能藏在运行时默认行为里。

一句收束（可直接进你文章）

元工程不把哲学当背景装饰，而是把每一门哲学分支还原成软件系统里一个可被形式化声明、可被证明、可被替换的结构：本体论管“有什么”，逻辑学管“能推什么”，伦理学管“准做什么”，政治哲学管“谁先做什么”，美学管“用多少的公理把前四者说干净”。它们不是隐喻，是同一张范畴图里不同投影面的显式契约。

这里要先跟你对齐一下：哲学系教材里其实没有唯一法定的“五个分支”，常见分法是本体论、认识论、逻辑学、伦理学、美学这五支（很多入门书/通识课就按这个列），有时候会把政治哲学或语言哲学顶掉美学塞进去，所以“五支”本身就是一个可争议的约定，不是天定的。

按你前面那套“元工程分类框架只收元问题、不收应用实例”的口径，最干净、也最贴合你已搭好的表的，就是这套经典五支：

1. 本体论 Ontology —— 存在什么、对象与关系何以成立

→ 元工程：系统里有哪些对象/状态/关系（U1+U5）

2. 逻辑学 Logic —— 什么推得出什么、有效推理的边界

→ 元工程：规约的可推演性、证明义务、逻辑系统本身可互译（institution 层）

3. 认识论 Epistemology —— 知识如何被证成、可知与不可知的边界

→ 元工程：可观测态 vs 内部态、审计/证书作为知识载体、抽象层的不可知边界

4. 伦理学 Ethics —— 行为的正当性、义务与责任归属

→ 元工程：操作的允许/禁止/应当模态、责任归因字段、审计追责

5. 美学 Aesthetics —— 形式的秩序、节制、合目的性

→ 元工程：规格的结构节制（最少公理、最少越界、R 的描述复杂度），不是 UI 好看

政治哲学、语言哲学、心灵哲学这些不进这五支，不是因为它们“不重要”，而是它们要么可归到伦理学的治理延伸（政治哲学→规约修订权，如你刚纠的那点），要么是现代分析哲学后加出来的“第六、第七支”，硬塞进五支里反而会破坏你框架的古典底盘。

如果你文章里想显式交代一句“为什么是这五支、为什么不放政治哲学”，可以直接用这句收：

取古典五支而非现代扩展清单，是因为元工程要的是对形式化活动本身的五类元追问（有什么 / 能推什么 / 知什么 / 准做什么 / 怎样算干净），政治哲学对“修订权”的追问可收进伦理学的权利-义务基底，不必另立一格抢元层位置。
